# Platformer Playground (Godot 4.6)

Игра, плейграунды и конструктор уровней. Запуск: Godot → Import → project.godot → F5 → главное меню
(«Играть уровень»; «Разработка» → плейграунды и конструктор — только в dev-сборке и из редактора).

**Вся техническая документация — в Obsidian: хранилище ART → заметка «Технология» и папка «Технология/».**
Там: архитектура, правила разработки, каталог общих функций, описание каждой механики и таблицы всех параметров.
Здесь намеренно ничего не дублируется.

Быстрые команды:
- создать недостающие data/*.tres и пресеты:  godot --headless --path . --script tools/generate_data.gd   (перезаписать всё: -- --force)
- создать записи каталога объектов (catalog/common/*.tres):  godot --headless --path . --script tools/generate_catalog.gd
- таблица параметров для заметки:  python3 tools/params_to_md.py data/wave_params.gd
